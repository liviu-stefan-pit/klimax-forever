The shippable WoW add-on. Copy this folder into `Interface/AddOns/` to install it. It is Lua 5.1, has no external dependencies and never touches protected functions.

How it works (version 0.8, `docs/DYNAMIC_GUIDE_PLAN.md`):

- `World/` is the compiled quest graph and is generated by `python -m pipeline compile-world`; never edit it by hand. `Data/` holds small curated runtime tables, `Locale/` the UI strings.
- `State/` reads the game: the quest log, the completed flags, and the reconciler that gives every quest a state. The game is the truth.
- `Plan/` is the planner: it scores what to do next and sequences it (`Planner.lua`), adds service stops (`Services/`) and class beats (`Class/`), and explains itself (`Explain.lua`).
- `Engine.lua` hands the plan to the window (`UI.lua`), the arrow, the step menu and the Plan view. The player's choices (skips, hidden steps, pin) are saved per character.
- `Telemetry.lua` records steps whose target was not where the data said, locally only (`/klimax report`).

Commands: `/klimax` (window), `plan`, `why [n]`, `whynot <quest>`, `forecast`, `view`, `report`, `profile`, `resync`, `reset [guide|all]`, `dump`, `debug`.
