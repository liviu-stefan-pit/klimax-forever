Derived data. `data/raw/` holds the QuestieDB extract (`quests.json`, `npcs.json`, `manifest.json` and so on). It is large, regenerated by `python -m pipeline extract`, and git-ignored. `data/horde/` holds hand-curated Horde inputs: `travel.json` (zones, flight paths, inns), `bands/` (quest packs for each band) and `curated/` (per-band keep, drop and optional decisions). `data/ui_maps.json` is the generated area-id to uiMapID table (from QuestieDB's Forever zone files; written by `python -m pipeline extract`). `data/raw/game/` (git-ignored) holds facts read from the installed game's add-ons by `python -m pipeline game-data`; see `docs/GAME_DATA.md`.
