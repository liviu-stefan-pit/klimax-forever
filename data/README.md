Derived data. `data/raw/` holds the QuestieDB extract (`quests.json`, `npcs.json`, `manifest.json` and so on). It is large, regenerated by `python -m pipeline extract`, and git-ignored. `data/horde/` holds hand-curated Horde inputs: `travel.json` (zones, flight paths, inns), `bands/` (quest packs for each band) and `curated/` (per-band keep, drop and optional decisions).
