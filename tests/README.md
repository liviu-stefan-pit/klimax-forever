Test assets for the add-on. `tests/lua/` holds the busted specs and `wowstubs.lua`, which stubs the WoW API for the step engine, reward scorer and bag check (phase 06 onward). Python tests live in `pipeline/tests/`.

**Save-state fixtures (phase 18).** `tests/fixtures/*.json` are characters replayed by the specs. A real one comes from the game: run `/klimax dump`, `/reload`, then `python -m pipeline fixture WTF/Account/<account>/SavedVariables/Klimax.lua --out tests/fixtures/<name>.json`. `tests/lua/fixture.lua` loads one into the stubs (`Fx.start(Fx.load("<name>"))`: player, position, quest log with collapsed headers and failed quests, completed quests, saved step state) and replays login and the first sync. `hunter15_synthetic.json` is hand-built from the level 15 Hunter report (its `_note` says how); replace or join it with a real dump when one arrives.

**Hunter replay.** `tests/lua/hunter_replay_spec.lua` replays that report on the plan engine (the phase 18 known failures KF1-KF10 as statements about the plan). The old `hypotheses_spec.lua` and the band-engine specs were removed in phase 29 with the engine.

**Planner vectors.** `tests/vectors/planner/*.json` are small worlds with an expected plan. `tests/lua/planner_spec.lua` runs them through the add-on planner and `pipeline/tests/test_sim_planner.py` through the Python mirror (`pipeline/sim/planner.py`); both must agree. `weights.json` is generated from `Klimax/Plan/Weights.lua` (the Lua spec fails when it is stale).

**Simulation and golden plans (phases 25 to 28).** `tests/lua/sim_spec.lua` runs 45 characters from level 1 to 40 on the real world with the add-on's planner and reconciler; `pipeline/sim/harness.py` does the same in Python for 135 race/class/profile combinations (`pipeline/tests/test_sim_harness.py`, about 90 s). `tests/golden/plans.json` holds the first plan steps of five default characters at levels 1, 10, 20, 30 and 39; both sides must produce it. After an intended planner or data change: `python -m pipeline.sim.harness --golden`, review the diff, commit it. Telemetry and explain specs: `telemetry_spec.lua`, `explain_spec.lua`; the engine: `engine_spec.lua` (`W.showSteps` in `wowstubs.lua` puts fixed steps in the window).
